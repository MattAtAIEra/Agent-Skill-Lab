# Example — minimal bedtime story

A 6-scene, 9-line bedtime story to demonstrate the full pipeline end-to-end. Run it once to verify everything works on your machine.

## What's in this folder

```
minimal/
├── BEDTIME.subs.json    ← 11 subs (9 spoken + intro/outro silence)
├── scenes.json          ← 6 scenes using 4 different types
├── README.md            ← this file
└── audio/               ← (generated by TTS — not committed)
```

## Run the pipeline

### 1. Install dependencies

```bash
pip install python-pptx pdfplumber Pillow  # only needed for extract scripts
# (TTS scripts and build_html.py use stdlib only)
```

### 2. Generate TTS audio

```bash
export VOAI_API_KEY=iq-xxx
python3 ../../skills/narrated-deck/scripts/tts_voai.py \
  BEDTIME.subs.json \
  --out audio/ \
  --speaker 語安 \
  --style 故事
```

Expected output: 9 mp3 files (`audio/BEDTIME-002.mp3` through `BEDTIME-010.mp3`).

### 3. Build the HTML

```bash
python3 ../../skills/narrated-deck/scripts/build_html.py \
  --subs BEDTIME.subs.json \
  --scenes scenes.json \
  --theme children \
  --out index.html \
  --crumb "narrated-deck demo ‧ 一個睡前故事"
```

### 4. Open in browser

```bash
open index.html       # macOS
xdg-open index.html   # Linux
start index.html      # Windows
```

Press Spacebar to play. Use ← / → to jump scenes.

## Try changes

### Swap to corporate theme (no narration changes needed)
```bash
python3 ../../skills/narrated-deck/scripts/build_html.py \
  --subs BEDTIME.subs.json \
  --scenes scenes.json \
  --theme corporate \
  --out index.corporate.html
```
Open `index.corporate.html` — same content, different look.

### Translate to English
1. Copy `BEDTIME.subs.json` → `BEDTIME.en.subs.json`
2. Translate each sub's `text` to English
3. Regenerate audio with ElevenLabs:
   ```bash
   export ELEVENLABS_API_KEY=sk_xxx
   python3 ../../skills/narrated-deck/scripts/tts_elevenlabs.py \
     BEDTIME.en.subs.json --out audio.en/
   ```
4. Build:
   ```bash
   python3 ../../skills/narrated-deck/scripts/build_html.py \
     --subs BEDTIME.en.subs.json \
     --scenes scenes.json \
     --theme children \
     --lang en \
     --audio-dir audio.en \
     --out index.en.html
   ```

## Expected runtime

| Step | Time |
| --- | --- |
| TTS (9 subs) | ~30s with Voai |
| Build HTML | < 1s |
| Total | ~30s end-to-end |

## What this demonstrates

- Per-subtitle mp3 architecture (each sub plays its own file)
- Scene grouping (multiple subs per visual scene)
- Empty subs with `dur` for visual breathing room
- 4 scene types used: `title`, `generic`, `cards-2`, `outro`
- Theme swappable without touching content or audio
- Children's theme — bigger fonts, rounder corners, playful colors

If this example runs end-to-end, the plugin is working. Build your own project off this structure.
