1這是什麼？

narrated-deck 是一個 Claude plugin / skill。給它一份 PPT、PDF、或寫好的大綱，它會交付一個資料夾：

my-project/
├── index.html        ← 自包含播放器（CSS/JS inline，無 CDN 依賴）
├── subs.json         ← single source of truth：scenes + 字幕
├── scenes.json       ← 視覺內容（每場景型別 + props）
└── audio/
    ├── PROJ-001.mp3  ← 一段字幕 = 一個 mp3
    ├── PROJ-002.mp3
    └── ...

瀏覽器打開 index.html 就播。可以掛靜態主機、可以螢幕錄製成 mp4、可以放 USB 給人離線看。

什麼時候用

  • 政府／企業培訓影片（衛生局 A1/B1 就是用這條管線出的）
  • 產品 demo / SaaS 解說
  • 兒童故事 / 繪本
  • 合規／法規更新通知
  • onboarding / 新人培訓

什麼時候不要用

  • 要做給人現場「翻投影片」用 → 用 pptx skill
  • 要做書面報告 / Word 文件 → 用 docx skill
  • 要做純 audiobook（沒視覺）→ 直接用 tts_voai.py 腳本就好，不用整套

2三種安裝方式

選一個適合您角色的：

A. 開發模式 — 直接連 source（推薦給 Matt 自己用）

plugin source 在：

讓 Claude Code 設定中加這條 plugin path（具體欄位看 Claude Code 版本，可能是 ~/.claude/settings.json 的 plugins.sources）：

✓ 為什麼推薦這個
您改 SKILL.md / scripts 即時生效，免重打包。比 .plugin 安裝多一層便利。

B. .plugin 安裝 — 給 IQT 同仁、給客戶

把 narrated-deck-v0.1.0.plugin 檔（60KB、zip 格式）給對方。對方：

  1. 在 Cowork 介面：拖進去或雙擊 → 自動裝
  2. 或命令列：unzip narrated-deck-v0.1.0.plugin -d ~/.claude/plugins/narrated-deck
  3. 重啟 Claude Code / Cowork

C. 手動 git clone（給有 git workflow 的人）

未來推上 GitHub 後：

git clone https://github.com/iqtechnology/narrated-deck ~/.claude/plugins/narrated-deck
ⓘ 包裝為 .plugin 的意義
.plugin 是 zip 改副檔名，純粹「為了分享」的格式。對作者本人意義不大，對接收者意義大 — 一個檔解決，不用懂結構。

3API Keys 設定

plugin 內 沒有任何 API key 寫死（這是刻意的 — 寫死就會跟著 .plugin 漏出去）。所有 TTS 腳本都讀環境變數：

VOAI_API_KEY
Voai.ai 配音用（zh-TW 首選）。從 voai.ai 取得。
ELEVENLABS_API_KEY
ElevenLabs 配音用（英語首選 / 多語備援）。從 elevenlabs.io 取得。
⚠ 絕對不要做的事
  • 把 key 寫死在 .py 檔內，然後 commit 到 git
  • 把 .env 檔 commit 到 git
  • 把 key 直接放在共用對話 / chat 紀錄裡（這份筆記也有遮掉）

三種設定方法

方法 A：當下 shell 用（測試）

# 開一個 terminal、暫時設 key
export VOAI_API_KEY='iq-xxxxxxxxxxxxxxxx'
python3 tts_voai.py A1.subs.json --out audio/

關掉 terminal 就消失。適合一次性 / 測試。

方法 B：永久存在 shell rc（推薦給天天用的人）

編輯 ~/.zshrc（macOS 預設）或 ~/.bashrc，加：

export VOAI_API_KEY='iq-xxxxxxxxxxxxxxxx'
export ELEVENLABS_API_KEY='sk_xxxxxxxxxxxxxxxx'

存檔後 source ~/.zshrc 或重開 terminal。從此每個新 shell 都自動有。

方法 C：專案 .env 檔（推薦給多 key、多專案的人）

每個專案目錄下放 .env：

# .env 內容
VOAI_API_KEY=iq-xxxxxxxxxxxxxxxx
ELEVENLABS_API_KEY=sk_xxxxxxxxxxxxxxxx

跑指令前把 .env 注入環境：

set -a; source .env; set +a
python3 tts_voai.py A1.subs.json --out audio/
⚠ .env 必加進 .gitignore！
echo ".env" >> .gitignore

怎麼確認 key 有設好

# 看當前 shell 有沒有 VOAI_API_KEY
echo "VOAI: ${VOAI_API_KEY:+SET}${VOAI_API_KEY:-NOT_SET}"
echo "ELL : ${ELEVENLABS_API_KEY:+SET}${ELEVENLABS_API_KEY:-NOT_SET}"

沒有 key 的 fallback：HTML 也能跑

如果只想先看視覺、字幕配時，不想花 TTS 額度：直接跑 build_html.py 不跑 tts 腳本。HTML 內建虛擬時間軸，會按估計秒數推進場景、不出聲音。覺得結構 OK 了再補 TTS。

4怎麼觸發、怎麼用

裝好後，對 Claude 講話就行（不用記指令）：

場景範例 prompt
政府培訓「用 narrated-deck，做 A2 模組，主題：複雜案件處理流程」
產品 demo「用 narrated-deck，把這份產品 PPT 做成 8 分鐘 narrated explainer，product 主題」
兒童故事「用 narrated-deck，把這個故事做成兒童繪本動態頁，children 主題」
多語「narrated-deck，把 A1 翻成英文版，視覺保持不變」
內部培訓「用 narrated-deck，做新人入職第一週的合規介紹，corporate 主題」

Claude 接到後會主動：

  1. 問 2–4 個 clarifying 問題（audience、tone、長度、語言、主題）
  2. 從您給的 PPT/PDF 抽取大綱（或從 prose 直接合成）
  3. 寫旁白草稿給您看，等您改
  4. 切成字幕陣列（subs.json）
  5. 跑 TTS 生 mp3
  6. 產 scenes.json + 合成 index.html
  7. 交付資料夾，您可以打開、可以丟主機、可以螢幕錄成 mp4

內建主題

government
深綠 + 米色。政府機關、衛生局、合規培訓。
product
Indigo + 天藍。SaaS demo、產品發表、銷售素材。
children
粉黃綠 + 大字。兒童故事、繪本、學齡教材。
corporate
海軍藍 + 灰。B2B 解說、leadership 簡報、投資人介紹。

切主題只要重跑 build_html.py 加 --theme product，不用重做 TTS、不用改場景內容。

5Quick start：跑一遍 example

plugin 內附了一個小範例（睡前故事），確認管線跑得起來：

cd /Users/matt/labs/agent-skill-lab/narrated-deck/examples/minimal/

# 1. 設 key（這 session 用）
export VOAI_API_KEY='iq-xxxxxxxx'

# 2. 跑 TTS（9 段 mp3，約 30 秒）
python3 ../../skills/narrated-deck/scripts/tts_voai.py \
  BEDTIME.subs.json \
  --out audio/ \
  --speaker 語安 \
  --style 故事

# 3. 開瀏覽器看（HTML 已經 build 好了）
open index.html

# 4. 試試換主題
python3 ../../skills/narrated-deck/scripts/build_html.py \
  --subs BEDTIME.subs.json \
  --scenes scenes.json \
  --theme corporate \
  --out index.corporate.html
open index.corporate.html

同一份內容，--theme 換一下就是不同視覺，audio 完全共用。

6疑難排解

症狀原因解法
ERROR: set VOAI_API_KEY env var 沒設環境變數 看上面「方法 A/B/C」
HTTP 401 / "invalid api key" key 錯字、或過期 到 voai.ai 重生 key，更新 ~/.zshrc
HTTP 429 / "rate limit" 呼叫太快 tts_voai.py --sleep 1.0 拉慢間隔
某字唸錯（例如「一疊」→「一爹」） Voai 模型對某詞 mispronounce 改 subs.json 該段文字（換同義詞），--only 023 --force 只重生那一段
瀏覽器打開沒聲音 audio/ 沒跟 index.html 同目錄 把 audio/ 資料夾複製到 index.html 旁邊
HTML 字幕跟音檔不同步 subs.json 改了但 HTML 沒同步 跑 scripts/sync_subs.py index.html PROJ.subs.json
Cloud Run 部署 403 OneDrive sync 把檔案改成 mode 600 Dockerfile 加 chmod -R a+rX（衛生局案有 reference）
