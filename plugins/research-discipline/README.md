# research-discipline

研究紀律 Plugin — 提供 Claude Code 在撰寫政府委託研究案、政策研究報告、技術評估報告、智庫報告時應遵循之研究身段紀律。

## 包含的 Skills

| Skill | 說明 |
|-------|------|
| `government-research-stance` | 政府委託研究案研究身段：技術幕僚而非政策制定者；點到即可，留決策空間給主管機關 |

## 適用情境

本 plugin 適用於：

- 政府委託研究案（如 OECD AI 倡議研析、數位發展部標案、各部會委辦研究）
- 政策研究報告
- 技術評估報告
- 智庫研究產出
- 任何研究團隊以「技術幕僚」身分產出之文件

**不適用於**：產品開發文件、商業簡報、學術論文（學術論文有自己的體例）、公司內部策略討論。

## 核心原則

> 做好本身的角色，留給上層主管決策的空間。

研究團隊之 5 角定位：

1. 整理工具屬性對照（節省主管機關蒐集時間）
2. 執行黑箱測試與驗證（提供證據基礎）
3. 觀察國外應用情境（為決策安心採用提供前置研究）
4. 提出技術可行性方向（如 API/MCP/Agent 元件之概念示範）
5. 留給主管機關依其法定職權處理具體政策實施

## 安裝

在專案的 `.claude/settings.json` 加入：

```json
{
  "plugins": [
    "/path/to/agent-skill-lab/plugins/research-discipline"
  ]
}
```

或使用 `/install-plugin` 指令。

## 使用方式

Skill 會在符合觸發條件（撰寫政府委託研究案、政策建議、技術評估報告等）時自動啟用。
